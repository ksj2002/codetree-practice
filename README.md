# codetree-practice

코드트리에서 푸는 코딩테스트 문제 풀이를 자동으로 백업하는 레포입니다.

## 소개

Java/Spring 백엔드 개발자 취업 준비 과정에서 매일 알고리즘 문제를 풀며 기록을 남기기 위해 만들었습니다. 코드트리 GitHub 연동 기능을 통해 정답으로 채점된 제출만 자동 커밋됩니다.

## 규칙

- 코드트리 연동일(2026년 8월 이후) 이후 제출한 문제부터 기록됩니다.
- 정답 제출만 커밋되며(오답/런타임 에러 제외), 구조는 v2(문제별 폴더) 기준입니다.
- 언어는 Java를 기본으로 사용합니다.

## 사용 목적

- 취업 준비 기간 동안 꾸준한 문제 풀이 습관 기록
- 포트폴리오/이력서 제출 시 코딩테스트 준비 이력 증빙
